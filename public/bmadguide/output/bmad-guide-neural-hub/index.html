01 — ENTENDA O MÉTODO

Uma equipe de IA.
Uma direção: a sua.

O BMAD organiza o desenvolvimento em papéis, documentos e fluxos. Cada agente contribui com uma perspectiva; você orienta o trabalho e valida os resultados.

01 /

Especialistas em colaboração

Produto, arquitetura, desenvolvimento e qualidade trabalham a partir do mesmo objetivo, com responsabilidades claras.

02 /

Decisões com participação humana

Você aprova requisitos, avalia alternativas e revisa entregas. A responsabilidade continua com quem conduz o projeto.

03 /

Fluxos em linguagem natural

Descreva o problema e siga perguntas orientadas. Os artefatos registram o que foi decidido para a etapa seguinte.

04 /

Contexto que acompanha o código

Histórias e especificações carregam decisões, restrições e critérios de aceite, reduzindo a necessidade de explicar tudo de novo.

DO PEDIDO SOLTO AO TRABALHO ESTRUTURADO

Não comece pelo código.
Comece pelo que precisa resolver.

Um pedido bem definido vira um plano proporcional ao problema. Um plano útil vira contexto para a implementação. A revisão fecha o ciclo e alimenta a próxima decisão.

Objetivo→Contexto→Entrega
↗

Planejamento proporcional

⌘

Agentes como arquivos

⊞

Um ecossistema extensível

Method, Builder, Creative Intelligence, Test Architect e Game Dev atendem necessidades diferentes.

↻

Aprendizado a cada ciclo

bmad pm plan-project

# Fase 3: Solução — níveis 3 e 4

bmad architect solution-architecture
bmad architect tech-spec # Por épico, no momento necessário

# Fase 4: Implementação

bmad sm create-story # Elaborar história
bmad sm story-ready # Aprovar para desenvolvimento
bmad sm story-context # Gerar contexto
bmad dev dev-story # Implementar
bmad dev story-approved # Marcar como concluída
