# BMAD Guide - edição Neural Hub

Este pacote contém o site completo em português, com a v6.12 estável e a prévia v7.

Extraia o ZIP mantendo as pastas. Abra index.html no navegador.

Para servir por HTTP, execute nesta pasta: python3 -m http.server 8000
Depois abra http://localhost:8000/.

Rotas: página principal, about/ e demo/. Recursos PDF e roteiro Markdown estão em recursos/. Fontes e licenças estão incluídas.

O progresso e as tarefas são locais ao navegador. O assistente usa respostas locais. Nenhuma instalação ou execução do BMAD é realizada pelo site.

O código de desenvolvimento está no projeto local /Users/andrecardia/Github/Bmad. As instruções de instalação do BMAD foram conferidas em fontes oficiais em 13/10/2026.
