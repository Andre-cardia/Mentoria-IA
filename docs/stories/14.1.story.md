# Story 14.1 — Trilhas de aprendizagem

## Status

InReview

## Story

**Como** aluno da mentoria,
**Quero** ver os cursos organizados em trilhas do básico ao avançado,
**Para que** eu saiba por onde começar e qual é o próximo passo.

## Contexto

A plataforma tinha apenas `modules → lessons`, exibidos como uma lista única de 27 cursos. O dono do produto aprovou a divisão dos cursos já gravados em três trilhas (9 básicos, 10 intermediários, 8 avançados) e pediu, na mesma leva, uma área de "Cursos de Formação" separada da mentoria, sinalizada como "Em breve".

## Acceptance Criteria

### AC1 — Modelo de dados
- [x] Tabela `tracks` (slug, título, descrição, nível, ordem) com RLS no mesmo padrão de `modules`
- [x] Coluna `modules.track_id` (nula, `on delete set null`)
- [x] Migração idempotente cria as 3 trilhas e distribui os 27 cursos atuais na ordem aprovada, sem tocar cursos que já tenham trilha

### AC2 — Página do aluno
- [x] `/cursos` agrupa os cursos por trilha, com nível, descrição, total de cursos e progresso da trilha
- [x] Cursos sem trilha aparecem em "Outros cursos" (nunca somem)
- [x] Sem a tabela `tracks` (migração pendente), a página mantém a lista simples

### AC3 — Admin
- [x] Formulário de curso permite escolher a trilha; a lista mostra a trilha de cada curso
- [x] Sem trilhas cadastradas, o seletor não aparece e nada é enviado

### AC4 — Cursos de Formação
- [x] Item "Formações" no menu com selo "Em breve"
- [x] Rota `/formacoes` com página de "Em breve", separada dos cursos da mentoria

## Scope

### IN
- Migração, agrupamento em `/cursos`, seletor no admin, página de formações

### OUT
- Novo tema visual (cinza + laranja) e novo player de aula
- Separação dos ambientes de ensino, administrativo e comercial
- CRUD de trilhas no admin (as 3 trilhas vêm da migração)
