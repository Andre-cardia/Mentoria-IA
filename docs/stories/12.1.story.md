# Story 12.1 — Recuperação de Senha

## Status

Ready for Review

## Story

**Como** usuário cadastrado na plataforma Mentoria IA,
**Quero** poder recuperar minha senha via e-mail,
**Para** retomar o acesso à plataforma caso eu esqueça minha senha.

## Critérios de Aceite

- [ ] AC-1: `LoginPage` exibe link "Esqueci minha senha" que navega para `/plataforma/esqueci-senha`
- [ ] AC-2: `ForgotPasswordPage` contém input de e-mail e botão de envio; ao submeter, chama `supabase.auth.resetPasswordForEmail()` com `redirectTo` apontando para `/plataforma/redefinir-senha`
- [ ] AC-3: Após o envio, a mensagem exibida é ambígua: "Se este e-mail estiver cadastrado, você receberá um link em breve" — sem revelar se o e-mail existe
- [ ] AC-4: O botão de envio fica desabilitado durante o loading para evitar múltiplos envios
- [ ] AC-5: `ResetPasswordPage` é acessível via link do e-mail (token na URL); contém inputs de nova senha e confirmação
- [ ] AC-6: Validação inline impede submit quando as senhas não coincidem — erro exibido antes do envio
- [ ] AC-7: `PasswordStrengthIndicator` exibe o nível de força da senha (fraca/média/forte) em tempo real ao digitar
- [ ] AC-8: Ao submeter nova senha válida, chama `supabase.auth.updateUser({ password })` e redireciona para `/plataforma/login` com mensagem de sucesso "Senha redefinida com sucesso. Faça login."
- [ ] AC-9: Ao acessar `/redefinir-senha` com token expirado ou inválido, exibe mensagem de erro e opção de reenviar o link
- [ ] AC-10: Ao acessar `/redefinir-senha` diretamente (sem token), redireciona para `/esqueci-senha`
- [ ] AC-11: Todos os componentes seguem o design system existente (CSS vars `var(--bg)`, `var(--accent)`, `var(--panel)`, fontes Space Mono/Space Grotesk, inline styles — sem Tailwind ou CSS modules)

## Dev Notes

### redirectTo
O `redirectTo` deve apontar para a URL pública da plataforma + `/plataforma/redefinir-senha`. Em desenvolvimento local, usar `http://localhost:5173/plataforma/redefinir-senha`. Configurar como variável de ambiente ou derivar de `window.location.origin`.

```js
const redirectTo = `${window.location.origin}/plataforma/redefinir-senha`;
await supabase.auth.resetPasswordForEmail(email, { redirectTo });
```

### Evento PASSWORD_RECOVERY
O Supabase emite o evento `PASSWORD_RECOVERY` via `onAuthStateChange` quando o usuário acessa o link do e-mail com token válido. `ResetPasswordPage` deve escutar este evento para saber que pode aceitar a nova senha.

```js
useEffect(() => {
  const { data: { subscription } } = supabase.auth.onAuthStateChange((event) => {
    if (event === 'PASSWORD_RECOVERY') {
      setCanReset(true);
    }
  });
  return () => subscription.unsubscribe();
}, []);
```

### PasswordStrengthIndicator — Lógica de Força
```js
function getStrength(password) {
  let score = 0;
  if (password.length >= 8) score++;
  if (password.length >= 12) score++;
  if (/[A-Z]/.test(password)) score++;
  if (/[0-9]/.test(password)) score++;
  if (/[^A-Za-z0-9]/.test(password)) score++;
  if (score <= 2) return 'fraca';
  if (score <= 3) return 'média';
  return 'forte';
}
```
